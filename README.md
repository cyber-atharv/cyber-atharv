## 🛡️ About Me

I am a **Cybersecurity Engineer & Systems Programmer** dedicated to building resilient defensive infrastructure, advanced binary analysis tools, and high-performance network security systems. 

- 🔭 **What I'm currently working on:** Low-level network scanning engines in **Zig**, kernel telemetry using **eBPF**, and automated vulnerability triage pipelines.
- ⚡ **Core Philosophy:** Security is an engineering discipline. Real-world protection requires deep visibility across the full stack—from hardware/kernel primitives to application layer protocols.
- 🛠️ **Portfolio:** Authored and architected **42 open-source security tools** spanning foundational network utilities to advanced threat detection platforms.
